How the flow works

	1.	The HL7 inbound service chain builds a message event object and publishes it to a Service Bus topic (working name: message-event).
	2.	Two subscriptions listen on that topic:
	•	Message Tracking receives every event.
	•	Message Insights receives only the event types it filters for.
	3.	A function app listener is triggered by the message and passes it to the service over gRPC. The function app → service gRPC link already exists, though it may need small changes. The new work is only the publishing side, in the inbound chain.
